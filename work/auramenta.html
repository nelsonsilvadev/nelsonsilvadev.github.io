Auramenta

A private journal for iPhone, built with React Native, Expo and TypeScript.

View on the App Store ↗ Visit website ↗

What I built

Journaling and local data

Journal entries with photos and voice notes, SQLite storage, mood tracking and goals. Text analysis happens on the device.

Backup and subscriptions

Encrypted iCloud backup and restore, plus RevenueCat subscriptions and purchase restoration.

The mobile interface

Reusable components, navigation and animations built with Redux Toolkit, React Navigation and Reanimated.

Testing and releases

Automated tests with Jest and React Native Testing Library. EAS Build and EAS Update for building and delivering the app.
